.. _add_skill_lesson_ref:

Add a Skill to a Lesson
=======================

**In this article, you will learn how to:**

* :ref:`Assign a Skill to a Topic <assign_topic_ref>`
* :ref:`Create a new Subtopic <create_subtopic_ref>`
* :ref:`Assign a Skill to a Subtopic <assign_subtopic_ref>`

Once you publish a Skill, it will be available in the **Skills** tab on the **Topics and Skills Dashboard**. To find the Skill, use the **Status**, **Sort**, and **Keyword** fields in the **Filter** panel to search for it.

.. figure:: /images/admins/skills_dashboard_filter.png
   :alt: Skills Dashboard filter panel
   :align: center

   *Fig. 1. Skills Dashboard Filter Panel*

---

.. _assign_topic_ref:

Assign a Skill to a Topic
-------------------------

Assigning a Skill to a Topic keeps it organized with related material and allows lesson creators to add that Skill to their lessons.

**To assign a skill to a Topic:**

1. In the **Topics and Skills Dashboard**, find your Skill.
2. Next to the **Unassigned** label, select the **three vertical dots**.
3. In the dropdown menu, select **Assign to Topic**.
4. In the dialog box that appears, search for the Topic you want.

   .. figure:: /images/admins/assign_skill_topic_dialog.png
      :alt: Dialog to assign a skill to a topic
      :align: center

      *Fig. 2. Dialog to assign a skill to a topic*

5. Select the Topic from the list. It will highlight in green when selected.
6. Select **Save** to assign the Skill to the Topic.

.. _create_subtopic_ref:

Create a Skill and Assign it to a Subtopic
------------------------------------------

When you assign a Skill to a Topic, it is initially placed under the **Uncategorized Skills** section. To help learners review Skills more effectively, you should group them into logical **Subtopics**.

Create a Subtopic
~~~~~~~~~~~~~~~~~

1. In the **Topics and Skills Dashboard**, select the topic you want to update.
2. In the **Topic Editor**, scroll to the **Subtopics** section. If no Subtopics exist, all Skills appear below the red **Uncategorized Skills** banner.

   .. figure:: /images/admins/subtopics_panel.png
      :alt: Subtopics panel in the Skills Dashboard
      :align: center

      *Fig. 3. Subtopics panel in the Topic Editor*

3. Select **+Add Subtopic**.
4. In the **Create new subtopic** dialog, complete the following fields:

   * **Title**
   * **URL fragment** (used to generate the subtopic's permanent link)
   * **Explanation** (a short description of the subtopic)
   * **Thumbnail image**

   .. figure:: /images/admins/create_subtopic_dialog.png
      :alt: Create New Subtopic dialog
      :align: center

      *Fig. 4. Create New Subtopic dialog*

5. Select **Create Subtopic**.

---

.. _assign_subtopic_ref:

Assign a Skill to a Subtopic
----------------------------

Once created, Subtopics appear below the **Uncategorized Skills** section.

**To assign a Skill to a Subtopic:**

1. Select the **three vertical dots** next to the skill you want to assign.
2. Select **+Assign to Subtopic** from the dropdown menu.
3. In the dialog that appears, select the **radio button** next to the Subtopic. The selection will highlight in green.

   .. figure:: /images/admins/assign_to_subtopic_ui.png
      :alt: Subtopics assignment interface
      :align: center

      *Fig. 5. Assigning a Skill to a Subtopic*

4. Select **Assign**.

Unassign a Skill from a Subtopic
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. Select the **three vertical dots** next to the Skill you would like to remove.
2. Select **Remove from Subtopic**.

   .. figure:: /images/admins/remove_from_subtopic.png
      :alt: Remove from subtopic interface
      :align: center

      *Fig. 6. Removing a Skill from a subtopic*

.. warning::
   Each Subtopic must contain a unique set of Skills. Do not assign the same Skill to more than one Subtopic within the same Topic.
