Merge a Skill
=============

Merging a Skill is useful when you have overlapping content that fits better under an existing, published Skill. This helps keep the Skill Tree lean and prevents creators from having to maintain redundant content.

**In this article, you will learn how to:**

* :ref:`Merge a skill into another existing skill <merge_steps_ref>`

---

.. _merge_steps_ref:

How to Merge a Skill
--------------------

1. In the **Topics and Skills Dashboard**, select the **Skills** tab and find the Skill you want to merge.
2. Next to the **Unassigned** or **Assigned** label, select the **three vertical dots**.
3. Select **Merge Skill** from the dropdown menu.

   .. figure:: /images/admins/skill_dropdown_menu_merge.png
      :alt: Skill dropdown menu on the Skills Dashboard
      :align: center

      *Fig. 1. Skill dropdown menu on the Skills Dashboard*

4. In the dialog that appears, search for and select the Skill you want to merge into.
5. Select **Done** to complete the merge.

.. warning::
   Merging is a permanent action. Ensure that the target Skill completely covers the pedagogical scope of the Skill being merged, as the original Skill will be deleted after the process is complete.
