Create a New Topic, Story, or Chapter
=====================================

In this article, you will learn how to:

* :ref:`Create a new Topic <create_topic_step_ref>`
* :ref:`Create a new Story <create_story_step_ref>`
* :ref:`Create a new Chapter <create_chapter_step_ref>`

---

.. _create_topic_step_ref:

Create a New Topic
------------------

1. Hover over your profile and select the **Topics and Skills Dashboard**.
2. In the **Topics** tab, select **Create New Topic.**

   .. figure:: /images/admins/create_topic_button.png
      :alt: Create New Topic button
      :align: center

      *Fig. 1. Create New Topic button*

3. Enter the topic name, URL, web title fragment, and description.
4. Select **Create Topic.**

   .. figure:: /images/admins/new_topic_info.png
      :alt: New topic information panel
      :align: center

      *Fig. 2. New topic information*

---

.. _create_story_step_ref:

Create a New Story
------------------

1. Select **Topics** in the **Topics and Skills Dashboard.**
2. Select the **three-dot menu** on the right of an Exploration and select **Edit**.

   .. figure:: /images/admins/edit_menu_dashboard.png
      :alt: Edit menu in the dashboard
      :align: center

      *Fig. 3. Edit menu in the Topics and Skills Dashboard*

3. Select **Add Story** under the **Canonical Stories** panel.
4. Add the details of the Story and select **Create Story**.

   .. figure:: /images/admins/create_story_dialog.png
      :alt: Create a new story dialog
      :align: center

      *Fig. 4. Create a new story dialog*

5. To save a draft, select **Save changes**. You can access the draft in the **Topic Editor**.
6. To publish, select **Publish Story**.

---

.. _create_chapter_step_ref:

Create a New Chapter
--------------------

1. To create a new Chapter for the story in the Topic Editor, select **Add Chapter.**

   .. figure:: /images/admins/add_chapter_button.png
      :alt: Add Chapter button
      :align: center

      *Fig. 5. Add Chapter*

2. Add a chapter title, Exploration ID, and thumbnail image.
3. Select **Create Chapter.**

Import an Exploration
~~~~~~~~~~~~~~~~~~~~~

When you create a chapter, you will need to complete the following:

* **Chapter Outline:** Enter a description of what the lesson will entail to guide Exploration creators.
* **Exploration ID:** Import a published Exploration by :ref:`entering its ID <_edit_a_lesson_ref>`. You cannot publish the Story without this step.
* **Prerequisite Skill IDs:** Select Prerequisite Skills based on those identified in the :ref:`Skill Tree <create_skill_tree_ref>` by selecting **Add prerequisite skill**.
* **Acquired Skill IDs:** Select acquired skills for this lesson based on those identified in the :ref:`Skill Tree <create_skill_tree_ref>` by selecting **Add acquired skill**.

---

New Chapter Navigation
----------------------

Select **Add a new destination chapter** to create subsequent chapters for the story. As you create Chapters, they will appear in a list on the left-hand side.

* Select the new Chapter from the list to import another Exploration and select Skills.
* Continue adding chapters as needed for the Story.
* Select **Save changes** and **Publish story** once complete.
