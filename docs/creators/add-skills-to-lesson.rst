===================================================
Add prerequisite and acquired skills to a lesson
===================================================

In this article, you will learn how to:

* :ref:`prerequisite_skills_ref`
* :ref:`acquired_skills_ref`
* :ref:`add_skill_to_chapter_ref`

.. _prerequisite_skills_ref:

Prerequisite skills
===================

Prerequisite skills are concepts a learner should already understand before 
beginning a new lesson. These are foundational skills that support the learner 
as they advance into a topic. 

These skills help generate review questions at the beginning of a lesson, which 
help determine whether the learner is ready to move forward or needs to revisit 
earlier material.

.. note::
   You can add any skill from any topic as a prerequisite skill.

.. _acquired_skills_ref:

Acquired skills
===============

Acquired skills are skills a learner will learn throughout the lesson. These 
are directly connected to the lesson’s content. The questions linked to these 
skills help learners study and practice the lesson content.

.. note::
   Acquired skills must be assigned to the topic before they can be added to a 
   chapter.

.. _add_skill_to_chapter_ref:

Add a skill to a chapter
========================

To add a skill to a chapter:

1. In the **Topics and Skills Dashboard**, select the topic that contains the 
   chapter/lesson. This will take you to the **Topic Editor**.
2. In the **Canonical stories** panel, select the story you want to update. 

.. figure:: /images/creators/canonical_stories_panel.png
   :alt: The Canonical Stories panel in the Topic Editor showing a list of available stories.

   *Fig. 1. Canonical Stories panel* 3. In the **Story Editor**, select the chapter you want to update from the 
   **Chapters** panel.

.. figure:: /images/creators/chapter_control_panel.png
   :alt: The Chapter Control panel within the Story Editor showing individual lesson chapters.

   *Fig. 2. Chapter Control panel*

4. In the **Chapter editor**, scroll down to the **Skill requirements and 
   achievements** panel.
5. Select **+Add prerequisite skill** or **+Add acquired skill**.

.. figure:: /images/creators/skill_requirements_panel.png
   :alt: The Skill Requirements and Achievements section showing buttons to add prerequisite and acquired skills.

   *Fig. 3. Skill Requirements and Achievements panel*

6. In the dialog that appears, select the skill you want to add.
7. Select **Save** to assign the skill to the chapter.
