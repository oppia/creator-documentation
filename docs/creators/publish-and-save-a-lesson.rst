Save and publish a lesson
=========================

You can only publish an exploration that follows a clear logical path.
If you’re having trouble publishing your lesson, there’s likely an issue
with one or more cards.

To save and publish in the **Exploration Editor**:

1. Select **Save Draft** above the **Exploration Editor** navigation
   bar. This will ensure you publish the most up-to-date version.
2. Select **Publish** above the **Exploration Editor** navigation
   bar. You will enter additional details about your exploration
   such as a goal, a category, tags etc.
3. Select **Save Changes** when you’re finished.

Your lesson is now live on the Oppia platform. You can view or share the
exploration at any time using the exploration link.

Remember, your exploration ID is the letters and numbers that appear
*after* “/explore/.”

.. _navigating_publishing_issues_ref:

Navigating publishing issues
============================

If the option to publish is greyed out, there is an unresolved structure
or logic issue. In the **Exploration Editor** panel, review each warning
icon in the cards. It will highlight issues like:

-  Isolated cards (cards not connected to the main path)
-  Interactions that loop indefinetely

Once you’ve resolved your lesson’s functionality issues, the **Publish**
button turns green, indicating that you can now publish your
exploration.
